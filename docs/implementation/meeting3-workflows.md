## Исключения пользователя

Не менять скрытие общей базы контактов, механизм ролей и scopes, телефоны и
их валидаторы, WinWidget, сессионные токены/завершение сессий. Не реализовывать
полный «светофор», пользовательскую палитру, состояние «Отложено» по дальнему
сроку, разграничение тёзок по городам и несогласованный технический backlog.

## Проверка и выпуск

Сохранить dirty forms, workspace/membership fencing, READ_ONLY, текущие ACL,
версии и стабильные commandId. Production-примеры встречи не изменять.
Новые таблицы требуют аддитивных service-owned миграций, ACL inventory и
штатного reviewed release hook; исторические миграции не переписывать.

Проверить затронутые frontend и сервисы, негативные случаи прав и повторы,
интеграцию PostgreSQL 18. Затем точные SHA dev/prod и зелёный CI, единый
согласованный backend → frontend выпуск через GitHub CI/CD, независимый
postflight образов/config/env/миграций/ACL/readiness/restarts/OOM.
Живые операции между сотрудниками, внешняя доставка и переподключение ящика
не считать подтверждёнными по CI или healthcheck.

## Состояние

Реализация и review завершены. Локальная проверка включает сборку frontend,
lint/typecheck, HTTP-регрессии и интеграционные сценарии PostgreSQL 18 для
почты, обращений, передачи сделок и вложений. Commit и выпуск через CI/CD
выполняются после окончательного общего прогона.

Первый выпуск использует `chat_env_install=false`: отдельный ограниченный
S3-ключ ещё не предоставлен. Код и миграция включены в этот же релиз, но
загрузка вложений остаётся выключенной до проверки ключа и включения через
reviewed CI/CD installer. Действующий почтовый ключ возвращает HTTP403 на
`chat/`; расширять его доступ или использовать backup key нельзя.

Для уже отключённого `design@ybs.one` encrypted secret отсутствует. Владелец
должен штатно переподключить существующий ящик; исправление worker сохраняет
секрет при следующих временных READ_ONLY, но не восстанавливает удалённый.
Импорт конкретного пропущенного письма и живая приёмка между сотрудниками
остаются отдельными неподтверждёнными проверками.
